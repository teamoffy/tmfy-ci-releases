# Pulumi resource provider binaries used by the deployments, one row per
# provider:
#
#   <name> <version> <gh-repo>
#
# The version is pinned, not tracked (like graalvm.txt): bump the row when the
# deployment bumps its provider, and the next run mirrors the missing release
# as pulumi-plugin-<name>/v<version>. Assets are
# pulumi-plugin-<name>-<version>-<linux-x64|linux-arm64|darwin-arm64>.tar.zst,
# staging pulumi-resource-<name> at usr/local/bin/ (extract at /).
#
# The upstream tarball is pulumi-resource-<name>-v<version>-<os>-<arch>.tar.gz
# from the row's <gh-repo> release, verified against its GitHub asset digest.
# Providers whose SDKs reuse another provider's plugin need no row of their
# own: the CRD extension SDKs all use the `kubernetes` binary.
