# OCI image mirrors — one line per tracked image:
#   <name> <registry/repo> <gh-owner/repo> <sed>
#
# <name>            product suffix; releases are tagged oci-<name>/v<version>
# <registry/repo>   image repository to pull (public, anonymous)
# <gh-owner/repo>   GitHub repo whose latest release tag is the image's version,
#                   or "pin:<tag>" for a literal pinned tag (chart-pinned
#                   images and registries with no release source; bump the pin
#                   in this file to update)
# <sed>             expression applied to the release tag to get the image tag,
#                   "-" for none (e.g. k3s releases are v1.x.y+k3sN but the
#                   docker tag is v1.x.y-k3sN). Unused for pin: rows.
#
# "Latest" is the upstream GitHub latest release — registry tag listings are
# unordered and paginated (ghcr caps /tags/list at 100 per page), so they
# cannot resolve latest. If a release tag has not been pushed to the registry
# yet, the image is skipped and picked up by the next run. A pin: row whose
# tag is missing fails the check.
#
